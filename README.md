## 🚀 Featured Projects

### 01 · Interactive Landing Page

An interactive marketing website focused on smooth scrolling, advanced animation, and 3D experiences.

**Stack:** React · JavaScript · GSAP · ScrollTrigger · SplitText · Lenis · Three.js · React Three Fiber · Zustand

**What I built**
- Smooth scrolling with Lenis and a `requestAnimationFrame` loop
- Scroll-driven animation systems using GSAP ScrollTrigger and SplitText
- Three.js / React Three Fiber scene with custom shader particles and scroll-linked 3D models
- Global scroll state managed with Zustand
- Structured development workflow with build and lint checks
